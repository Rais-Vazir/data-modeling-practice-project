# data-modeling-practice-project
This project turns a messy 23-sheet Excel extract of a B2B retail business (60 customers, 63 products, 80 orders, 20 cities across 5 regions, Feb 2025 – Oct 2026) into a clean galaxy (multi-fact) star schema in Power BI. Raw data issues were fixed in Power Query: the 2025 and 2026 order files were combined, monthly inventory columns were unpivoted, comma-separated promoted SKUs were split into rows, and a duplicate shipments sheet was removed. The model has conformed dimensions (dim_date, dim_customer, dim_product, dim_geo, dim_order_flag, dim_campaign) shared by multiple fact tables with different grains: sales, order process (accumulating snapshot), inventory (periodic snapshot), campaign performance, promotion coverage (factless) and sales targets. It supports analysis of revenue and margin, target attainment, order-to-cash cycle time, campaign performance and inventory trends. Row-level security restricts each regional manager to their own region's data. The project demonstrates Kimball-style dimensional modeling, Power Query cleaning, DAX measures and RLS.
